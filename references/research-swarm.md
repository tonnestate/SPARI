# Research Swarm

Use cheap breadth and stronger judgement.

## Scouts

- GitHub Whole-Product Scout
- GitHub Framework Scout
- GitHub Implementation Scout
- PyPI Primary Scout
- PyPI Alternative Scout
- Internal Reuse Scout
- Security/Maintenance Scout
- License/Provenance Scout

Scouts collect evidence.

A Technical Evaluator compares.

A Contrarian Reviewer checks for:

- overlooked candidates;
- popularity bias;
- README-only claims;
- hidden integration cost;
- unnecessary custom code;
- license/provenance errors;
- stronger compositions.

Use cheaper agents for recall-heavy discovery and stronger agents for decisions.
