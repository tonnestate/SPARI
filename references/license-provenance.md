# License & Provenance

Workflow control, not legal advice.

No external artifact enters a reusable deliverable without a license and provenance decision.

Check:

- canonical upstream;
- fork status;
- exact version/commit;
- applicable license;
- per-file/directory exceptions;
- bundled third-party material;
- intended use;
- notices/attribution;
- redistribution obligations;
- compatibility with target distribution.

States:

REFERENCE_ONLY / PATTERN_ONLY / DEPENDENCY_ALLOWED / CODE_REUSE_ALLOWED / REVIEW_REQUIRED / DENIED

Missing, conflicting, or unclear licensing fails closed.

For PyPI, link where possible:

package → version → hashes → source repo → tag/commit → provenance/attestation → inspected source
