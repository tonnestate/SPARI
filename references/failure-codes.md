# Failure Codes

## Admission / research

- `NOT_RECON_READY`
- `ECONOMY_GATE_UNDECIDABLE`
- `REUSE_INDEX_UNAVAILABLE`
- `REUSE_INDEX_STALE`
- `GITHUB_UNAVAILABLE`
- `PYPI_UNAVAILABLE`
- `INTERNAL_CONTEXT_UNAVAILABLE`
- `RESEARCH_INCOMPLETE`
- `RESEARCH_BUDGET_EXHAUSTED`

## Runtime evidence

- `CANONICAL_ENTRYPOINT_UNKNOWN`
- `NOT_REPRODUCED`
- `RUNTIME_EVIDENCE_INCOMPLETE`
- `EXECUTION_PATH_UNVERIFIED`
- `FIRST_FAILURE_UNKNOWN`
- `NOT_IN_RUNTIME_PATH`
- `RUNTIME_PATH_CONFLICT`
- `RUNTIME_CUSTOM_DELTA_UNJUSTIFIED`
- `SAME_PATH_RETEST_MISSING`
- `FAILED_CYCLE_CAP_REACHED`

Runtime evidence failure never implies permission to patch nearby code or build a replacement architecture.

## Composition / execution

- `CUSTOM_DELTA_UNJUSTIFIED`
- `EXECUTION_CONTRACT_MISSING`
- `EXECUTION_OUTCOME_MISSING`
- `EXECUTION_SCOPE_DRIFT`
- `CUSTOM_DELTA_EXPANDED_UNJUSTIFIED`
- `REVISION_EVIDENCE_MISSING`
- `OUTCOME_NOT_VERIFIED`

## Case / trajectory

- `INTERNAL_MAP_INCOMPLETE`
- `ENGINEERING_CASE_INSUFFICIENT`
- `TRAJECTORY_EVIDENCE_MISSING`
- `RECOMPOSITION_UNJUSTIFIED`
- `RECOMPOSITION_EVIDENCE_MISSING`
- `INTERVENTION_SURFACE_UNKNOWN`

Discovery, runtime-path uncertainty, budget exhaustion, or recomposition failure never implies permission to build from scratch or continue blind trial-and-error.

Preserve the last supported evidence state and surface the unresolved gap.
